# UnicodeSecurity

Unicode identifier spoofing and ambiguity detection for Elixir.

> **Development status:** Unicode 18 data is currently draft. This package is not
> releasable until the final Unicode 18 data is published and pinned.

`unicode_security` is a pure-Elixir package for building comparison keys and
detecting potentially confusing Unicode identifiers. A skeleton is a comparison
key, not a canonical identifier or replacement value.
